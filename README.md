**Global Airbnb Performance Dashboard**
**Project Overview**

This Power BI dashboard analyzes Airbnb marketplace performance across major global cities from 2008–2021.

The project explores:

1. Marketplace growth trends
2. Supply and demand dynamics
3. Superhost penetration
4. Pricing analysis
5. Guest engagement
6. Customer review patterns

**Business Questions Answered**

##### Growth Analysis

1. How did Airbnb listings evolve over time?
2. When did Airbnb experience peak growth?
3. What was the impact of COVID-19?

###### Market Share Analysis

1. Which cities have the largest Airbnb inventory?
2. How significant is Superhost presence across cities?
3. Which cities demonstrate the strongest demand intensity?

###### Pricing \& Guest Experience

1. Which room types command the highest prices?
2. Which cities deliver the best guest experience?

###### Guest Engagement Analysis

1. Which cities generate the most reviews?
2. Which cities have the highest reviews per listing?
3. How has guest engagement changed over time?

**Tools Used**

1. Power BI
2. Power Query
3. DAX
4. Data Modeling
5. Data Visualization

**Key Insights**

1. Entire Room is the dominant room type.
2. Airbnb experienced peak listing growth in 2015.
3. COVID-19 resulted in a 96% decline in new listings.
4. Paris generated the highest total guest engagement.
5. Rome achieved the highest demand intensity (reviews per listing).
6. Mexico City recorded the strongest overall guest experience scores.

**Interactive Features**

1. Bookmark-based page navigation
2. Toggle buttons for Demand Intensity and Market Size analysis
3. Dynamic KPI cards
4. Multi-page dashboard design
